# Personal

Skills tied to my own setup, not promoted in the plugin.

- **[idea-to-wave](./idea-to-wave/SKILL.md)**: Shape a high-level product idea into an approved interpretation, then use plan-wave to file agent-ready issues.
- **[orchestrate-wave](./orchestrate-wave/SKILL.md)**: Orchestrate implementation of a wave of agent-ready issues: dispatch implementer subagents in worktrees, verify PRs, audit their /code-review verdicts, merge with approval.
- **[plan-wave](./plan-wave/SKILL.md)**: Plan a wave of features and file them as fully-specified, agent-ready issues with dependency edges and a dispatch order.
